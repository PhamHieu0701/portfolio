# Pham Ly Thanh Hieu — Portfolio

Personal portfolio of a Backend / Full Stack PHP Developer based in Ho Chi Minh City, Vietnam.

6+ years of experience with PHP applications, SQL optimization, real-time messaging, API integrations, and production support.

## What you will find

- About, technical skills, and developer-verified AI-assisted workflow
- Selected work at SePay, IncepIT, and LiFull Tech VN
- Experience, education, and contact links

## Stack

Astro 5, Tailwind CSS 4, and TypeScript. Static output hosted on GitHub Pages.

## Development

```sh
npm ci
npm run dev
```

```sh
npm run build
npm run preview
```

## Updating content

- `src/config.ts`: profile, skills, projects, experience, education, and social links
- `src/pages/index.astro`: page layout and scoped styles
- `src/styles/global.css`: Tailwind import and global styles
- `astro.config.mjs`: Astro and GitHub Pages configuration

## Checks and deployment

Pull requests targeting `master` run the build check. Changes pushed to `master` trigger the existing GitHub Pages deployment workflow. Review changes through a pull request before merging.
